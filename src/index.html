Comment jouer

🖱️
Clic gauche : se déplacer, et faire l'action évidente (parler à quelqu'un, passer une porte, regarder un décor).
✨
Clic droit (appui long sur mobile) : la roue des actions — Regarder 👁 · Prendre ✋ · Utiliser ⚙ · Parler 💬.
🎒
Inventaire : clique un objet, puis sa cible pour l'utiliser ou le donner, ou un autre objet pour les combiner. Clic droit sur un objet : le regarder.
👥
Ronds en haut : changer de personnage. Passer (Échap) saute un dialogue.

Clic : action · Clic droit / appui long : plus d'actions · Objet puis cible : utiliser ou donner
